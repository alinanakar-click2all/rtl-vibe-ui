# Components — الگوهای کامپوننت RTL-aware

این فایل الگوهای رفتاری و ساختاری کامپوننت‌ها را در RTL مستند می‌کند. قواعد بنیادی (Logical Properties) در `01-foundations.md` آمده‌اند و اینجا تکرار نمی‌شوند — فقط کاربردشان در هر کامپوننت.

---

## ۱. ناوبری (Navigation / Sidebar)

### ساختار
در RTL، سایدبار از **راست** شروع می‌شود. اگر از CSS Grid استفاده می‌کنی، نیازی به `direction` دستی نیست — گرید خودکار آینه می‌شود:

```css
.app {
  display: grid;
  grid-template-columns: 264px 1fr;  /* ستون اول = سایدبار */
}
